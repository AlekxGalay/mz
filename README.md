# Mazepa для Lampa

Плагін [Lampa](https://github.com/yumata/lampa-source) для телевізорів LG webOS: пошук і перегляд релізів з українського торент-трекера Mazepa.to прямо в інтерфейсі Lampa.

## Що вміє

- Кнопка **Mazepa** в картці фільму/серіалу: штатний екран торрентів Lampa з сідами, розміром, датою, сортуванням і фільтрами.
- **Рівні якості**: 0 — понад 35 ГБ, 1 — 4K (4K без HDR позначено `[SDR]`), 2 — FHD, 3 — решта. «Авто» показує найвищий наявний рівень; вручну — кнопкою «Рівень».
- Рядки на головній: **«Новинки Mazepa»** і **«Популярне на Mazepa (IMDb)»**.
- Пошук з меню плагіна (без картки) на тому ж штатному екрані.
- Відтворення через TorrServer.

## Вимоги

| Що | Для чого |
|---|---|
| LG webOS TV 2024–2026 | див. таблицю сумісності нижче |
| Lampa 3.4.5 | плагін звіряно з вихідним кодом цієї версії |
| TorrServer (MatriX) з доступом по мережі | відтворення торрентів; адреса вводиться в меню плагіна |
| Cloudflare Worker `mz-api` | вхід на Mazepa, пошук, `.torrent`, рядки на головній; код у `worker/` |
| Безкоштовний ключ OMDb | лише для рядка «Популярне (IMDb)» |

## Сумісність з моделями

| Покоління | Chromium | Стан |
|---|---|---|
| webOS 24 (2024) | 108 | Не перевірено |
| webOS 25 (2025) | 120 | **Перевірено** на LG 55QNED86T6A (модель 2024 року, її рушій показує Chromium 120), Lampa 3.4.5 |
| webOS 26 (2026) | 132 | Не перевірено. Код — чистий ES5 і не використовує нічого, чого немає в Chromium 108, тож очікується робота |

Покоління визначається за версією Chromium з user-agent і є підказкою, а не точною версією прошивки (її видно в налаштуваннях ТВ).

Таблиця версій Chromium береться зі сторінки розробників LG й може змінитись.

**Звук DTS.** За відкритими даними, LG прибрала DTS (включно з DTS:X) з ліній 2025 року: реліз із єдиною DTS-доріжкою на такому ТВ може йти без звуку. Це не обмеження плагіна. На 2023–2024 DTS був. Про 2026 надійних даних немає. Перевірити свій ТВ можна в меню: **Діагностика → Про пристрій і сумісність** (рядок «DTS: так/ні»).

## Встановлення

1. У Lampa додайте плагін за адресою `https://alekxgalay.github.io/mz/m.js`.
2. **Повністю закрийте й знову відкрийте Lampa.** ТВ тримає старий файл у кеші, і без перезапуску нова версія не завантажиться.
3. Меню **Mazepa** (Налаштування → Mazepa → «Відкрити Mazepa») → **TorrServer** → «Адреса» (наприклад `192.168.0.110:8090`) → «Синхронізувати з налаштуваннями Lampa».
4. **Прив'язка телевізора** → «Створити код прив'язки» → підтвердіть код на сторінці Worker `/pair` (потрібен адміністративний секрет власника Worker).

Плагін не містить адрес чи секретів: адреса TorrServer береться з налаштувань, токен прив'язки зберігається лише на самому ТВ.

## Своя інсталяція Worker

Код у `worker/`. Потрібні Cloudflare-акаунт і `wrangler`:

```
cd worker
npx wrangler kv namespace create MZ_SESSIONS   # вписати id у wrangler.jsonc
npx wrangler secret put MZ_ADMIN_KEY            # довільний довгий секрет
npx wrangler secret put OMDB_KEY                # ключ omdbapi.com (для рядка «Популярне»)
npx wrangler deploy --keep-vars
```

Далі відкрийте `https://<ваш-worker>/pair`, увійдіть акаунтом Mazepa і замініть адресу Worker у `m.js` (`var API`).

## Діагностика, якщо щось не працює

Меню **Mazepa → Діагностика**:
- «Журнал діагностики» (увімкнути) → відтворіть проблему → «Показати журнал».
- «Про пристрій і сумісність»: версія webOS/Chromium, Lampa, кодеки, чи відповідають Worker і TorrServer.

## Відомі проблеми

- Позиція перегляду на штатному екрані файлів **не зберігається** (діагностика в коді, причину ще не знайдено).
- Рівні й фільтри визначаються за назвою релізу, тож нестандартні назви можуть потрапити не в той рівень.

## Розробка

Один файл `m.js` (чистий ES5, без збірки). Перевірки в імітованому середовищі: `tests/` (запуск у `tests/README.md`). Робочі нотатки й архітектурні рішення: `CLAUDE.md`.
